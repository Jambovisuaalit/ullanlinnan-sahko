# Hyväksytyt V04-brand assetit

Kopioi tähän muuttamattomina hyväksytystä V04-logopaketista:

- `USOY_LOGO_HEADER_COMPACT_BLACK_RGB_SVG.svg`
- `USOY_LOGO_HEADER_COMPACT_PAPER_RGB_SVG.svg`
- `USOY_LOGO_FAVICON_BLACK_ON_PAPER_RGB_SVG.svg`
- `USOY_LOGO_FAVICON_BLACK_ON_PAPER_ICO_MULTI.ico`
- `USOY_LOGO_APPLE_TOUCH_BLACK_ON_PAPER_PNG_180X180.png`
- `USOY_LOGO_FAVICON_BLACK_ON_PAPER_PNG_192X192.png`
- `USOY_LOGO_FAVICON_BLACK_ON_PAPER_PNG_512X512.png`

Älä muuta SVG-polkuja, mittasuhteita, värejä tai logolukkoa. Älä rakenna logoa HTML-tekstinä.

`npm run verify:assets` estää tuotantobuildin, jos assetit puuttuvat.

Hyväksytty ikonikirjasto lisätään erilliseen `public/brand/icons/USOY_ICON_SPRITE.svg`-tiedostoon. Katso `public/brand/icons/README.md`.
