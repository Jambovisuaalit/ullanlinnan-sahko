# Manuaalinen saavutettavuustesti

Testaa vähintään etusivu, yksi palvelusivu, myymälä ja yhteystiedot.

1. Käytä koko sivu vain näppäimistöllä.
2. Avaa ja sulje palveludropdown Enterillä, välilyönnillä ja Escapella.
3. Avaa mobiilivalikko, kierrä Tab/Shift+Tab ja varmista focus trap.
4. Suurenna 200 %:iin 1280 × 1024 -viewportissa.
5. Testaa 320 CSS px leveys ilman kaksisuuntaista vieritystä.
6. Testaa Windows High Contrast / forced colors.
7. Testaa prefers-reduced-motion.
8. Testaa lomakkeen tyhjä lähetys, yksittäiset kenttävirheet, tiedostovirhe, verkkovirhe ja onnistuminen.
9. Tarkista lukujärjestys VoiceOverilla tai NVDA:lla.
10. Tarkista näkyvä fokus kaikissa interaktioissa.
